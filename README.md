# 📄 Fake API Posts Viewer

This is a simple web project that fetches and displays post data from a fake API using HTML, CSS, and JavaScript. It uses **Axios** and **async/await** to handle API requests.

## 🌐 Live Demo

> (https://emran71.github.io/Fetchapi_with_axios/)

## 🚀 Features

- Fetches data from [JSONPlaceholder](https://jsonplaceholder.typicode.com/posts)
- Uses Axios for API calls
- Handles async requests using `async/await`
- Clean and responsive layout
- Easy to understand and modify

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Axios

## 📁 Files Included

- `index.html` – The main HTML file
- `style.css` – Contains styling for the page
- `script.js` – Contains JavaScript code using Axios and async/await

## 📡 API Used

- Endpoint: `https://jsonplaceholder.typicode.com/posts`
- Method: `GET`
- Returns: An array of post objects (`id`, `title`, `body`)
